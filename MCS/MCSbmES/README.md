# BAACSS — Español (España)

Edición española de España. Utiliza los datos maestros en inglés y la lógica de la aplicación compartidos desde `../MCSbm/`, con las etiquetas traducidas en `js/i18n.js`.

Los elementos conservan el orden alfabético de sus nombres originales en inglés. El almacenamiento del navegador es independiente del de todas las demás ediciones lingüísticas.
