# DACSS — Português (Portugal)

Edição portuguesa de Portugal. Utiliza os dados mestres em inglês e a lógica da aplicação partilhados de `../MCSdx/`, com etiquetas traduzidas em `js/i18n.js`.

Os itens mantêm a ordem alfabética dos nomes originais em inglês. O armazenamento do navegador é independente de todas as outras edições linguísticas.
