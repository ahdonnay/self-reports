# BAACSS — Svenska

Svenskspråkig utgåva. Den använder gemensamma engelska grunddata och programlogik från `../MCSbm/`, med översatta etiketter i `js/i18n.js`.

Posterna ligger kvar i alfabetisk ordning efter sina ursprungliga engelska namn. Webbläsarlagringen är separat från alla andra språkutgåvor.
