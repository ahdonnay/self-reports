# MCS self-reports

This folder is the landing area for the Multiple Chemical Sensitivity (MCS)
self-report applications.

| Folder | Report | Status | Reserved browser-storage key |
|---|---|---|---|
| `MCSdx/` | Disorders (DACSS) | Available | `dacss.v1` |
| `MCSbm/` | Biomarkers | Placeholder | `mcsbm.v1` |
| `MCStm/` | Treatments | Placeholder | `mcstm.v1` |
| `MCSex/` | Exposures | Placeholder | `mcsex.v1` |

Each application is kept in its own folder so its HTML, CSS, JavaScript, data,
and saved answers remain independent of the other reports.

When GitHub Pages is enabled for this repository, the MCS menu is available at:

`https://ahdonnay.github.io/self-reports/MCS/`
