v.2026.10.13.a

このチェックリストについて

BAACSSは、一部の人々に化学感度に関連したバイオマーカー異常のチェックリストです。 これらの異常を抱えている人はMCSを持っていません。 しかし、統計的にはMCSの方が、これらの異常が制御よりも著しくなっています。 BAACSSは、高度、低、または参照範囲で最新の結果を記録するために人々のために設計されているので、彼らは彼らの臨床医は、彼らの結果がMCSとどのように密接に一致しているか、そして、最近ではなかったテストを見ることができます。 (このリストは、参照が利用可能である独立した毒性学者によってコンパイルされました。 Albert@DonnayDetox.com.)

注記: 項目は、英語の原名のアルファベット順に掲載されています。

BAACSSチェックリストを完了する方法

各バイオマーカーについては、いずれかを選択します。

  • 未 決して/結果無し = このテストがなかったり、結果へのアクセスがなかったり
  • 基 参照の範囲 =実験室の参照か正常な範囲内の結果
  • 低 低い = 参照範囲の下の結果
  • 高 高い/現在 = 参照範囲の上の結果、または通常が存在しない場合

すべてのバイオマーカーが始まります N. N を R、L、または H に、ラボや EHR の結果が手元にある場合にのみ変更します。 その日付を入力してください。 お問い合わせ, ヤンゴンまたは YYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYMM.MM.DD 続行する前に。 ダッシュボードは自動的に更新されます。 いつでも停止して戻ってきます。このブラウザで回答が保存されます。

ボトムライン これらのバイオマーカーのすべては、制御よりもMCSを持つ人々でかなり異常ですが、相関は常に原因ではありません。 バイオマーカーは、MCSの取得の危険性に寄与する共同ファクターであるか、またはMCS、共存性、または単なる偶然を得るという結果であるかもしれません。 MCSにマッチしないBAACSS結果は、結果として重要である。

重要: 自分のレポートに示されている分類を記録し、資格のある臨床医との結果を議論. このチェックリストは、診断を確立したり、試験所で供給された参照範囲と解釈を交換したりしません。

プライバシーとデータ
