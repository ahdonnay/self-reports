# DACSS — français québécois

Version française québécoise de la liste DACSS. Cette application réutilise les données, les liens, la logique de
calcul et la feuille de style de `../MCSdx/`; `js/i18n.js` contient les libellés localisés. Les réponses sont conservées
séparément dans le navigateur sous la clé `mcsdx.qfr.v1`.
