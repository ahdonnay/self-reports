# BAACSS — español norteamericano

Versión en español norteamericano del autoinforme BAACSS. La aplicación utiliza el motor y la lista maestra de
`../MCSbm/`, y aplica una interfaz y nombres de biomarcadores en español. Las respuestas se guardan por separado en
el navegador con la clave `mcsbm.nas.v1`.

Dirección publicada: <https://ahdonnay.github.io/self-reports/MCS/MCSbmNAS/>
