# BAACSS — français québécois

Version en français québécois de l’auto-évaluation BAACSS. L’application utilise le moteur et la liste maîtresse de
`../MCSbm/`, puis applique une interface et des noms de biomarqueurs en français. Les réponses sont enregistrées
séparément dans le navigateur sous la clé `mcsbm.qfr.v1`.

Adresse publiée : <https://ahdonnay.github.io/self-reports/MCS/MCSbmQFR/>
