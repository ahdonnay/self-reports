# TRACTSS — Suomi

Suomenkielinen versio. Se käyttää yhteisiä englanninkielisiä perustietoja ja sovelluslogiikkaa kansiosta `../MCStx/`; käännetyt tekstit ovat tiedostossa `js/i18n.js`.

Kohteet säilyvät alkuperäisten englanninkielisten nimien mukaisessa aakkosjärjestyksessä. Selain­tallennus on erillinen kaikista muista kieliversioista.
